# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 2.7.x | Yes |
| < 2.7 | No |

## Reporting a Vulnerability

Report vulnerabilities privately using [GitHub private vulnerability reporting / security advisories](https://github.com/jackwander/Laravel-Module-Maker/security/advisories/new).
Please do not open public issues for vulnerabilities.
